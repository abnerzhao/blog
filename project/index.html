Obsidian Highlight Clipper

Obsidian Highlight Clipper 是一个支持将网页内容高亮并一键保存到 Obsidian 的 Google Chrome 浏览器插件。

核心功能：

  • 阅读网页内容时支持高亮文本片段，类似微信读书划线效果
  • 支持将高亮文本内容一键保存到 Obsidian 笔记

上手使用：

  • 项目地址：GitHub GitHub - abnerzhao/obsidian-highlight-clipper: Capture what matters from the web, straight into Obsidian.
  • 安装地址： Obsidian Highlight Clipper - Chrome Web Store

Obsidian Link Title Plus

Obsidian Link Title Plus 是一个支持 Obsidian Markdown 链接标题生成插件。

核心功能：

  • Obsidian 笔记中网页链接格式化为 Markdown 链接，并展示网站图标
  • 支持自定义 Markdown 链接展示内容
  • 支持 HTTP、HTTPS 和 SOCKS5 代理抓取网页元数据

上手使用：

  • 项目地址：GitHub GitHub - abnerzhao/obsidian-link-title-plus: Link Title Plus automatically converts pasted HTTP(S) URLs into Markdown links with page titles and favicons.
  • 安装地址： Link Title Plus
